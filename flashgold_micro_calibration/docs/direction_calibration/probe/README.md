# Flow-proxy probe: can quotes reproduce the live order-flow verdict?

`probe_flow_proxy.py <project folder>` rebuilds every number of `../BRIEF.md` section 3 from `data/raw/XAUUSD/*/*.bi5` (835 hourly files, needs the
`hours` download of `tools/fetch_dukascopy.py`) and `results/real/real_trades_sar.csv`. Outputs next to the script: `probe_flow_proxy_metrics.csv`
(every candidate feature and model with AUCs and intervals), `probe_flow_proxy_label_algebra.csv` and the console log. The per-trade feature
table (3 MB) is regenerated by the script and not kept here. `verify_flow_label_algebra.py` enumerates which labels the EA's own rules allow
(243 vote/body/micro states per side). `check_hf_sizes.py` shows that the quote sizes of the Hugging Face copy are quantised like the raw ones.
Result: no quote-derived feature reproduces the label (best out-of-sample AUC 0.54 to 0.59, about 0.9 needed).
