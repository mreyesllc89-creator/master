# master

XPW Orientation TDI strategies for TradingView (Pine Script v6).

- `xpw_orientation_tdi_v2.8_strategy.pine` - current. Any chart timeframe from
  1 Sec to 1 Month, a "Signal rung" picker (chart rung, every rung, or one
  fixed rung), a trade action on every label row (off / enter / enter
  opposite / exit only), a "Reverse every label" switch, and the rung name on
  every label and order comment.
- `xpw_orientation_tdi_v2.4_strategy.pine` - earlier version, kept for
  reference.
