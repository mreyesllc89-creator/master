# GVLiveV2 FGF: one file per pair and timeframe

Same code as `GVLiveV2_Polymarket_PreCandle_Strategy_FGF.pine`; only the input defaults differ, chosen per pair and chart timeframe by one fixed rule (worst half, plateau, hold-out). Each file's header carries its full record. Costs included: gold $0.30 spread per round trip; BTC 0.02% per side + $0.20; no slippage. R = one stop distance.
